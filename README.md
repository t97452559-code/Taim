# سكينة — موقع أصوات الراحة (بالرمز لمرة واحدة)

## التشغيل
    node server.js                   # المنفذ 3000 (أو PORT=8080 node server.js)
    COOKIE_SECURE=1 node server.js   # عند النشر على HTTPS (مهم)

لا يحتاج أي مكتبات؛ يكفي Node.js 18 أو أحدث.

## إدارة الرموز
    node admin.js generate 100          # ينشئ رموزًا جديدة ويحفظها في codes-to-sell-التاريخ.txt
    node admin.js status                # كم رمز استُخدم وكم بقي
    node admin.js reset XXXX-XXXX-XXXX  # يحرّر رمزًا (مثلًا إذا غيّر العميل هاتفه)

## كيف يعمل
- كل رمز 12 خانة، ويُحفظ في seed-codes.json / codes.json مشفّرًا (SHA-256) فلا يمكن استخراجه من الملف.
- أول دخول بالرمز يربطه بجهاز المستخدم (كوكي مدتها سنة). نفس الجهاز يعود بدون إعادة إدخال الرمز.
- أي جهاز آخر يحاول نفس الرمز يُرفض: «الرمز مستخدم».
- ملفات الصوت في private-audio/ لا يخدمها الخادم إلا لمن لديه جلسة صالحة.
- حدّ للمحاولات الخاطئة: 8 محاولات كل 10 دقائق لكل عنوان IP.
- الدفع: تبيع الرموز بالطريقة التي تناسبك (تحويل، واتساب، متجر...) وتسلّم كل عميل رمزًا واحدًا.

## ملاحظات
- احتفظ بنسخة احتياطية من seed-codes.json / codes.json (فيه حالة الرموز المستخدمة).
- إن مسح العميل بيانات المتصفح فقد جلسته؛ استخدم reset لتحرير رمزه.
- ملف codes-to-sell فيه الرموز بشكلها المقروء: لا ترفعه إلى الاستضافة، وأبقه عندك فقط.
